# 信息概要页

每种费用类型生成一份独立的 A4 PDF，放在对应类型文件夹，不与证明材料合并。源文件固定为 `assets/信息概要的模版.pptx`。

## 填写内容

| 字段 | 取值 |
| --- | --- |
| 项目名称 | 模板已有项目名称后加全角括号中的费用类型 |
| 报销总金额 | 本类型清单的合计金额 |
| 报销人、电话 | 模板已填写的真实信息 |

先检查全部幻灯片文本，并与采购申请单模板一起收集缺失信息，一次向用户询问。空白、`XXX`、“姓名”“电话”等占位文字不能当作真实信息；项目名称、报销人或电话缺失时询问用户。金额占位值必须替换为本批金额。

## 保留模板并打印

复制模板到根目录 `tmp/` 后，只替换字段文字。不得修改字体、字号、颜色、下划线、文本框尺寸、位置或幻灯片比例；追加类型后若换行、溢出或遮挡，先请用户决定内容或修改模板。当前模板有项目名称、金额、报销人、电话四个 `XXX` 占位符；`print_summary_pages.ps1` 先检查标签与占位符顺序，再按此顺序替换，保持其他 XML 不变。若以后模板已填写真实信息，复用其值；四占位脚本不适用时改用 PowerPoint 在工作副本中只替换必要文字并原生打印，不改源模板或猜测替换位置。

用 PowerPoint 的 **Microsoft Print to PDF** 打印，纸张选 A4、整页幻灯片并适应纸张。不得“另存为 PDF”或为改变方向而调整幻灯片尺寸；横向 A4 是横向模板的正常打印结果。PowerPoint 只读打开工作副本，关闭时不保存。

单类型和多类型统一用 PowerShell 7 运行 `print_summary_pages.ps1 -TemplatePptx <模板> -JobsJson <任务文件> -ProjectName <项目名称> -Applicant <报销人> -Phone <电话>`；上述三项取模板中的真实信息或用户答复，不用脚本默认值代填。任务 JSON 是数组，单类型时仅放一项；每项包含 `category`、`amount`、`work_pptx` 和 `output_pdf`，后两者使用完整路径。脚本只启动一次 PowerPoint。输出名为：

```text
output/YYYYMMDD_类型_汇总金额/信息概要页_类型_汇总金额元.pdf
```

打印后核对：单页 A4、四项信息完整且金额与清单一致、无 `XXX`、品牌元素与文字版式完好，且没有证明材料页。
