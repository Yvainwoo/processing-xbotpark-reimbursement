# 证明材料 PDF

制作或修改 PDF 前，按 `pdf` skill 完成其要求的产物准备。用 `create_evidence_pdf.py` 读取已校验清单和根目录 `tmp/` 中的下载材料；`--out` 指向类型文件夹内的最终 PDF，`--temp-dir` 明确指向根目录 `tmp/<本类型批次>/evidence-images/`。用户同意凭证缺失但保留记录时，用 `--missing-notes` 提供逐项说明。

## 页面

- A4，每条记录一页，页边距 10 mm、凭证区内边距 4 mm；保持凭证原始比例，不裁剪。
- 页眉左侧为费用名称、右侧为金额；第二行只显示“序号　类型”。序号取多维表格“序号”字段原值，不能改成 PDF 页码。
- 上方放发票，下方左侧放订单凭证、右侧放付款凭证，区域用浅灰边框。
- 选用能显示中文的字体。凭证确实缺失且用户同意纳入时，只在对应区域标注用户给出的原因。

原始附件目录仍需单独交付；PDF 只是展示件。

## 核验

将每类的 `manifest`、`evidence_pdf`、`summary_pdf`、`qa_dir` 写入同一个 UTF-8 JSON 数组。清单和 QA 路径位于根目录 `tmp/`，两个 PDF 位于对应类型文件夹。一次运行 `verify_delivery.py --jobs-json <任务 JSON> --render`，核对页数、A4、逐页序号/名称/类型/金额、凭证区域及概要页内容。

脚本每四页生成一张联系表。人工查看所有联系表，只对异常页单独高分辨率渲染；修复截断、空白、乱码、重叠或无法辨读的材料后再交付。
