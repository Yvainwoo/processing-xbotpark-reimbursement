# 采购申请单规则

本规则只适用于“研发物料”报销的额外交付物，不替代信息概要页或类型证明材料。

## 数据筛选

1. 以本次已确认、通过校验的 `manifest.records` 为候选集，绝不扩大到历史或未纳入本次报销的记录。
2. 仅保留 `category` 恰为 `研发物料` 的记录。
3. 读取本次从飞书导出的原始记录 JSON，根据字段名（非固定列号）定位附件字段 `实物图`；仅当该字段的附件数组非空时纳入。
4. 不得把发票、订单凭证、付款凭证的附件存在与否当作“实物图”。非研发物料及无实物图的研发物料均不得出现在采购申请单中。
5. 输出前报告入选数量、取自多维表格“费用名称”的物资名称和金额合计；若为 0 条则不生成并报告原因。

## 模板填充

源模板：`assets/采购申请单模板.xlsx`，目标工作表：`模板`。

- 原模板只读保留。先复制为 `YYYYMMDD_采购申请单.xlsx`，然后仅替换下列已有内容单元格。不得设置或重设样式、字体、字号、边框、合并、行列尺寸、页边距、缩放、打印质量，亦不得改动其他工作表。
- 填写后，在打印前回读并比对模板与交付 XLSX 的 A4 纸张、纵向/横向、缩放和四边页边距；任何不一致都视为模板样式被改动，停止并从原模板重新复制填写。不可使用会重建工作簿或重置页面设置的导出流程。
- 表格有 21 个物资行（第 7 至 27 行）。超过 21 条时停止，先询问用户是否拆分为多份申请单；不得擅自压缩字体、行高或缩放。
- 申请人、申请部门：使用模板已有的真实值；若为空或为 `xxx`、`XXX` 等占位值，询问用户。只有用户已在同一轮报销任务中确认过该值时，才可复用。
- 申请时间、希望供货日期：生成当天。保持模板原有日期显示格式。
- 购置理由（`C5`）：本次入选记录的唯一类型以 `、` 连接；常见结果为 `研发物料`。
- 物资行从第 7 行开始按出现顺序连续编号。字段映射如下：

| 模板列 | 写入内容 |
| --- | --- |
| 序号 | 采购申请单内的连续序号，从 1 开始 |
| 物资名称 | 多维表格“费用名称” |
| 事由 | 多维表格“类型”（本流程为研发物料） |
| 单位 | `个` |
| 数量型号 | `1` |
| 单价 | 多维表格“金额” |
| 预算金额 | 多维表格“金额” |
| 预算支出 | 多维表格“金额” |
| 库存 | `0` |

第 28 行“预算金额”和“预算支出”均为入选金额的精确两位小数汇总。未使用的物资行只清除内容，绝不清除格式。

## A4 原生打印与检查

1. 必须使用 Excel 的 `Microsoft Print to PDF` 打印生成 PDF，不能使用 `ExportAsFixedFormat`、另存为 PDF 或自绘 PDF。此做法与信息概要页采用的“原生应用打印”原则一致；采购申请单模板是 XLSX，因此使用 Excel 而非 PowerPoint。
2. 只读打开交付 XLSX，保留其原始纸张、方向、缩放、页边距等设置。打印会话中可以将打印区域暂时限定为 `$A$1:$I$33`，仅为排除模板尾部空行产生的空白页；必须包含第 1 行，因为基地 Logo 和地址是锚定在该行的浮动图片。关闭时不得保存，因此 XLSX 的任何样式或打印设置不会变化。
3. `Microsoft Print to PDF` 可能异步写入文件。`PrintOut` 返回后，至多轮询 20 秒，确认目标 PDF 已存在且非空后再关闭应用；不应因即时文件检测失败而错误回退到导出方式。
4. 渲染并目视核验 PDF：A4 纵向、仅 1 页、无空白第 2 页；页眉中的基地 Logo 与地址完整可见；无裁切或重叠；标题、表头、19/实际入选条数、各行金额和两个汇总金额均清晰可见。

## 文件占用与安全替换

当正式同名 PDF 已存在时，默认不覆盖。只有用户明确要求重打或修复时才允许替换，且按以下顺序处理：

1. 先以 `tmp/qa/YYYYMMDD_采购申请单_待替换.pdf` 生成候选文件，并完成上述 A4、单页、Logo/地址和内容核验。
2. 如果移动或替换正式 PDF 遇到“文件被其他进程占用”，不得强制关闭、终止或干扰用户的 WPS/阅读器进程。保留候选文件，说明其路径，并请求用户关闭该 PDF 后再继续。
3. 用户确认已关闭后，将旧正式 PDF 移到 `tmp/qa/`（例如加后缀 `_缺页眉`）保留追溯，再将已核验候选文件移动为正式同名 PDF。不得删除旧版。
4. 替换后重新运行 PDF 元数据检查和页面渲染，确认最终路径的文件仍为 A4 单页且完整含有页眉图片。

## 推荐命令

```powershell
& scripts/build_procurement_application.ps1 `
  -TemplateXlsx assets/采购申请单模板.xlsx `
  -ManifestPath tmp/<本类型批次>/manifest.json `
  -RecordsPath tmp/records-0.json,tmp/records-200.json `
  -OutputXlsx output/YYYYMMDD_研发物料_<该类型汇总金额>/YYYYMMDD_采购申请单.xlsx `
  -Applicant <报销人> -Department <申请部门> `
  -ApplicationDate YYYY-MM-DD -Category 研发物料

& scripts/print_procurement_application.ps1 `
  -InputXlsx output/YYYYMMDD_研发物料_<该类型汇总金额>/YYYYMMDD_采购申请单.xlsx `
  -OutputPdf output/YYYYMMDD_研发物料_<该类型汇总金额>/YYYYMMDD_采购申请单.pdf `
  -SheetName 模板 -WaitSeconds 20
```

若目标文件已存在，先让用户确认是否替换；获确认后在 `tmp/qa/` 留存旧版，再使用 `-Overwrite` 重新生成 XLSX。PDF 脚本默认拒绝覆盖，须先将旧版移入 `tmp/qa/` 后再打印。
