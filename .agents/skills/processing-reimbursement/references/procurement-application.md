# 采购申请单

每批只制作一份采购申请单：本批清单中，飞书原始记录的“实物图”字段确有附件的条目全部汇总纳入，不限费用类型。每条入选记录填写一行；没有实物图的条目不纳入。不要用发票、订单或付款凭证代替实物图，也不要纳入本批清单之外的记录。先核对入选类型、总条数、物资名称和汇总金额；整批没有符合条件的条目就说明原因，不生成空表。申请单金额仅汇总入选条目，可能小于本批报销总金额。

## 填写 Excel 模板

复制 `assets/采购申请单模板.xlsx` 为交付 XLSX，仅填写“模板”工作表已有内容单元格。字体、字号、图片、边框、合并、行列尺寸及页面设置均保持原样。申请人和部门使用模板已填的真实值；为空或 `XXX` 时询问用户。申请时间与希望供货日期填生成当天，保留原显示格式。购置理由（`C5`）填写入选条目的所有实际费用类型，去重后以“、”连接；每行“事由”仍填写该条目的类型。

物资占第 7～27 行，单页最多 21 条。超过上限先确认同一份申请单的续页方式，仍交付一份 XLSX 和一份 PDF；不能缩小字体或行高，也不能按费用类型拆成多份申请单。未使用行只清除内容；第 28 行“预算金额”“预算支出”填全部入选条目的精确汇总。

| 列 | 填写内容 |
| --- | --- |
| 序号 | 申请单内从 1 开始连续编号 |
| 物资名称、事由 | 多维表格“费用名称”、类型 |
| 单位、数量型号、库存 | 默认“个”、1、0 |
| 单价、预算金额、预算支出 | 多维表格“金额” |

用 PowerShell 7 运行 `build_procurement_application.ps1` 一次，传入模板、完整的本批已确认清单、同批全部原始记录页、申请人/部门、申请日期和输出 XLSX 路径。脚本不按类型过滤；不要传入单类型清单遗漏其他类型。`-RecordsPath` 是路径数组；多页记录要在当前 `pwsh` 会话中传 `@('第1页.json','第2页.json')`，不要把逗号连接的路径作为一个字符串传给 `pwsh -File`。打印前回读模板与交付 XLSX 的 A4 纸张、方向、缩放和页边距；不一致时从原模板重新复制填写。

## 原生打印与验收

从交付 XLSX 用 Excel 的 **Microsoft Print to PDF** 打印，不使用另存为 PDF 或程序重绘。打印时可暂设区域 `$A$1:$I$33` 排除尾部空行，但必须包含第 1 行：基地 Logo 与地址锚定在那里。只读打开、打印后不保存工作簿。调用 `print_procurement_application.ps1` 时传入 XLSX、目标 PDF 和工作表“模板”；打印结果可能延迟出现，最多等待 20 秒。

交付路径为：

```text
output/YYYYMMDD_采购申请单.xlsx
output/YYYYMMDD_采购申请单.pdf
```

核对 XLSX 未使用行的 A～I 列均为空（尤其“库存”列不得留下模板的 `0`）。再核对 PDF 为 A4 纵向单页、无空白第 2 页；Logo、地址、全部物资行及两个汇总金额清晰完整。XLSX 样式与源模板一致。

## 重打或文件占用

正式文件已存在时先在根目录 `tmp/qa/` 生成并核验候选件。用户要求修复或重打后，才将旧版移入 `tmp/qa/` 留档，再放入候选件。若 WPS 或阅读器占用文件，请用户关闭后继续，不强行终止进程；替换后再次核对 PDF 页面和页眉。
